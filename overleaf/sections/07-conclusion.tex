\section{\bt{Conclusion}{结论}}
\label{sec:limitations}
\bi{\system{} turns calculations discovered in verified agent sessions into shared, parameterized metric and feature definitions guarded by explicit data conditions. Indexing validation outcomes by condition signatures and table versions lets \system{} recheck only what an update affects, share each check and repair across definitions and agents, and execute every reused metric on a snapshot where its conditions hold. Future work will extend maintained conditions to source authority and unit semantics, many-to-many joins, and incremental feature repair.}
{\system{} 将经核验的智能体会话所习得的计算转化为受显式数据条件保护的共享参数化指标与特征定义。通过按条件签名与表版本索引验证结果，\system{} 仅重查数据更新所影响的条件，跨定义与智能体共享每次检查与自动修复，并确保每个被复用的指标都在其条件成立的快照上执行。未来工作将把受维护条件扩展至权威数据源与量纲语义、多对多连接以及特征定义的增量修复。}
