# Paper Figure Generators

Vector PDFs in `overleaf/figures/` are generated by deterministic Python scripts sharing palette and typography rules from `style.py`, `mplstyle.py`, `vecfig.py`, `parts.py`, and `smallparts.py`. Data-driven figures verify plotted values against `overleaf/gen/*.tex` macros at build time.

| --- | --- | --- | --- |
| Fig. 1 | `metric-record.pdf` | `metric_record.py` | `exp/2026-10-01-workload-characterization/` |
| Fig. 2 | `architecture.pdf` | `architecture.py` | Schematic |
| Fig. 3 | `extraction.pdf` | `extraction.py` | Schematic + verified session values |
| Fig. 4 | `lookup.pdf` | `lookup.py` | Schematic + catalog lookup trace |
| Fig. 5 | `maintenance.pdf` | `maintenance.py` | Schematic + shared check trace |
| Fig. 6 | `relbench-cumulative.pdf` | `relbench_cumulative.py` | `exp/2026-10-20-relbench/paper-sessions.json` |
| Fig. 7 | `reuse-work.pdf` | `reuse_work.py` | `exp/2026-10-20-relbench/reuse-work-data.json` |
| Fig. 8 | `population.pdf` | `population.py` | `exp/2026-10-12-population/population-stats.json` |
| Fig. 9 | `change-study.pdf` | `change_study.py` | `exp/2026-11-01-change-study/study-stats.json` |

`mechanism.py` computes the feature-extraction summary macros in `overleaf/gen/mechanism.tex` from `exp/2026-10-29-mechanism-pilot/`.
