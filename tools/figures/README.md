# Paper Figure Generators

Vector PDFs in `results/figures/` are generated by deterministic Python scripts sharing palette and typography rules from `style.py`, `mplstyle.py`, `vecfig.py`, `parts.py`, and `smallparts.py`. Data-driven figures verify plotted values against macros in `results/gen/*.tex` (falling back to `reference_macros.json`) at build time.

| Paper Figure | Output PDF | Generator | Data Source |
| --- | --- | --- | --- |
| Fig. 1 | `metric-record.pdf` | `metric_record.py` | `exp/workload-characterization/workload-stats.json` |
| Fig. 2 | `architecture.pdf` | `architecture.py` | Schematic |
| Fig. 3 | `extraction.pdf` | `extraction.py` | Schematic + verified session values |
| Fig. 4 | `lookup.pdf` | `lookup.py` | Schematic + catalog lookup trace |
| Fig. 5 | `maintenance.pdf` | `maintenance.py` | Schematic + shared check trace |
| Fig. 6 | `population.pdf` | `population.py` | `exp/population-sharing/population-stats.json` |
| Fig. 7 | `change-study.pdf` | `change_study.py` | `exp/schema-evolution/study-stats.json` |
| Fig. 8 | `lookup-scale.pdf` | `lookup_scale.py` | `scale-summary.json` and `risk-coverage.json` in `exp/semantic-lookup/` |
| Fig. 9 | `shared-validation.pdf` | `shared_validation.py` | `exp/shared-validation/stats.json` |

`mechanism.py` computes the feature-extraction summary macros in `results/gen/mechanism.tex` from `exp/mechanism-studies/`.
